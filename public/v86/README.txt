BIOS images used by the v86 x86 emulator (Windows 98 in Boot Camp).

seabios.bin   SeaBIOS (https://www.seabios.org), LGPL-3.0, see COPYING.LESSER.
vgabios.bin   VGABIOS from the Bochs project / SeaVGABIOS, LGPL-2.1+, see COPYING.LESSER.
Both are the prebuilt images from https://github.com/copy/v86/tree/master/bios

The emulator itself is v86 (BSD-2-Clause, see LICENSE.v86), installed from npm.
